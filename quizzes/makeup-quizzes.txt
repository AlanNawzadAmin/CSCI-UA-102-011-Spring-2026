```
public class funnyList extends DoublyLinkedList<Integer>{
    public boolean equals(funnyList list2){
        if (size != list2.size()) return false;
        boolean equal_at_odd = true;
        for (int i = 0; i < list2.size()/2; i++){
            equal_at_odd = equal_at_odd && (getAtIndex(2*i+1) == list2.getAtIndex(2*i+1));
        }
        Integer sum1 = 0;
        Integer sum2 = 0;
        for (int i = 0; i < list2.size(); i++){
            sum1 = sum1 + getAtIndex(i);
            sum2 = sum2 + list2.getAtIndex(i);
        }
        return equal_at_odd && (sum1 == sum2);
    }
}
```

(b) (4 points) Based on this implementation of equals, implement a sensible version of hashCode().
